# Brief: ns-ui. You own ui/.
Read CLAUDE.md, docs/STATE.md, docs/CONTRACT.md (v3.2), docs/ref/ui.md, docs/ref/spacetimedb.md.
Build a Vite + React + TypeScript dashboard (`npm create vite` react-ts), `spacetimedb` package and `spacetimedb/react` hooks. Import bindings from ../agents/common/src/module_bindings (or copy them with a script). Connect as a viewer identity; it can only call submitRequest. Create the connection builder at module scope. Use `--host` so the phone can load it; never use localhost in the SpacetimeDB URL (use the laptop LAN IP via an env var, default ws://127.0.0.1:3000). Self-host fonts with Fontsource (venue Wi-Fi may be offline).
Views, all driven by table rows only (no fake animation): device cards (online/offline with heartbeat age), tally light mirror (idle green, pending amber pulse, active amber, expiring red, revoked red) derived from access_grant and events, grant list with live countdown (expiresAtUs), incident timeline (incident + events), command trace (event + run_result with exit code and health), change timeline showing status applied or rolled_back (read only), runbook trust counters with the promotion moment (trust.promoted), cost meter from cost.update events (tokens, usd, seconds, commands, presses) next to the $22 human level-1 ticket benchmark labelled "MetricNet via HDI", and a request box calling submitRequest(text) that shows the request status and result. Technical trace toggle for raw events. Phone-first responsive layout, dark and light themes.
Acceptance: run `cd agents/common && npx tsx src/test-auth.ts` and watch rows appear live; the request box creates a user_request row.
