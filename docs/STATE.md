## Idea (version 3.1, accepted)
- Pitch: "It's 3 a.m. A server goes down. Nobody wakes up, and it fixes itself." Monitoring is automated, execution is not.
- Self-healing by default with an autonomy ladder: 0 observe, 1 heal allowlist alone (snapshot, run, health check, auto-rollback), 2 ask (press), 3 hold (press and hold), never (policy forbids, e.g. hostile log text).
- Day-one allowlist: restart a down service and check its health endpoint; rotate (never delete) log folders when disk fills; restore known-good config; toggle phone Wi-Fi via adb.
- Earned trust: per-runbook counter, 3 verified successes promotes ask to alone. Circuit breaker: 2 failed fixes or 6 autonomous actions/hour/device stops and escalates.
- Rollback: `change` table with pre_state and inverse command. Reversible classes: file edit, service state, Android setting. Package install partly. Arbitrary or destructive: not reversible, press and hold.
- Workspaces per device type: `workspaces/<type>/SKILL.md` (runbook) and `policy.yaml` (read, write, destructive, autonomous, forbidden patterns). The gate classifies commands from policy, never from the agent.
- Lantern (FREE-WILi OG): LEDs as ambient state, buttons green approve / red deny or revoke all / white undo last change, display shows command and countdown, speaker chimes. With autonomy the light, kill switch and undo matter most, approval is for escalations.
- Cost meter in UI: real tokens times price, seconds, commands, human presses, next to the human L1 ticket benchmark ($22, MetricNet via HDI, range $6 to $35). Do not claim headcount savings or fleet ROI. Fine-tuning is a roadmap slide only.
- Audiences: B2B lead (IT, campus IT, MSP, data center), B2C one beat or closing line ("make a Manim video" or "clone this repo and deploy to Vercel" from the phone; needs internet and a token, stretch).
- Threat model, say out loud: we defend against a fooled or over-eager agent, not a compromised OS.
- Novelty (be honest, never say "first"): physical approval for agents exists (YubiKey 5.8 agent authorization, keycard-shell-mcp), JIT approval exists (Tailscale PAM and Aperture, Teleport MCP), AI IT remediation exists (SolarWinds AI Agent with MCP and runbook execution), Rubrik Agent Rewind sells undo, multi-device agent meshes exist (messh, multipi, profClaw, exo). Possibly open: ambient hardware indicator and kill switch across mixed devices, small teams. Win on execution, story, a demo that works. Edge: friend's IT experience (Cenovus network engineer, campus IT: SolarWinds, RDP, VNC, SSH).

## FREE-WILi diagnosis update (Oct 3, 23:45)
After a replug and a red-button shutdown + replug, `onewili.connect()` still hangs. Faulthandler shows it blocks in `serial.write()` inside `Transport.open()` (writes RESET_QUIET to the MAIN port /dev/ttyACM0). ## FREE-WILi ROOT CAUSE (Oct 3, 00:05): the board runs the WiLiDoro OG app, not an OneWili-compatible app
Evidence: USB product strings are `FWOG main wilidoro 001` / `FWOG display wilidoro 001` (format `FWOG <cpu> <app> <version>`), the display CPU CDC (ttyACM1) prints `[wilidoro] alive (panel=ok leds=ok audio=ok imu=ok) heap free=...` every second and ignores host writes, and the screen shows a Pomodoro timer ("25:00 READY 0/4", softkeys Start / Nearby / Menu). The main CPU CDC (ttyACM0) does not read host data, so onewili.connect() hangs on its first write. The published OG app catalog (https://docs.freewili.com/og-apps/apps.json) has only OG Vegas, WiLiDoro and Orca Field Notes: none exposes host control. OneWili docs target FreeWili 2.
Options: (1) ask Discord #free-wili; (2) install the deprecated legacy FW1 firmware via fwOGAppExplorer / fwogcli (Danger zone), after which the legacy `freewili` pip library works (VERIFIED examples: LEDs, text, tone, buttons in docs/ref/freewili.md); this removes the OG display bootloader and WiLiDoro, restorable via the same tool; on Linux fwogcli must be built from source (needs `sudo apt install -y ninja-build libudev-dev`; sources downloaded at scratchpad/fwOGAppExplorer, preset linux-gcc-release, target fwogcli); (3) fallback: phone browser as the Lantern.
